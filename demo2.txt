======================================================================
  数据分析Agent系统 v2 - 长链推理 + 多Agent协作
======================================================================

[核心痛点]
  1. 业务人员不会SQL  -> 自然语言提问即可
  2. 需求表达模糊      -> 意图理解Agent自动拆解
  3. AI生成SQL可能出错 -> SQL校验Agent自动检测+修复
  4. 有数据但看不懂    -> 数据解读Agent提炼洞察
  5. 不知道用什么图表  -> 可视化Agent智能推荐
  6. 报告制作耗时长    -> 报告Agent一键生成多格式

[核心逻辑流] (长链推理: 每一步输出是下一步输入)
  用户问题
    -> [意图理解Agent] 拆解分析意图
    -> [NL2SQL Agent]  基于意图生成SQL
    -> [SQL校验Agent]  自检测+自修复
    -> [数据查询Agent]  执行SQL获取数据
    -> [数据解读Agent]  提炼关键发现与洞察
    -> [可视化Agent]    智能推荐图表+生成
    -> [报告Agent]      整合输出组装报告
======================================================================
